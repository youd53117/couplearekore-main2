# 第2部署：記事執筆＋TikTok連動構成担当（02-writer）

本スキルは「カップルあれこれ（couple-arekore.com）」の記事制作ワークフローにおける **第2工程** です。
`01-research` から受け取った一次情報をもとに、`knowledge/brand-tone.md` と `knowledge/ng-rules.md` に100%準拠した記事本文・HTML骨格・TikTok連動セクションを執筆します。

## 執筆前に必ず読むファイル
1. `GEMINI.md`: レイアウト3パターン、レスポンシブ規定、必須 `<head>` 設定
2. `knowledge/brand-tone.md`: 文体トーン、HTMLコンポーネント、TikTok連動ブロック仕様
3. `knowledge/ng-rules.md`: 禁止表現、AI構文NG例、HTML構文の過去教訓
4. 参考テンプレート（該当パターンに応じて選択）:
   - パターンA: `article-perfume5.html`
   - パターンB: `article-yokohama.html` / `article-tokyo.html` / `article-nagoya.html`
   - パターンC: `article-aliba.html`

---

## ステップ1: パターン別HTML骨格の構築

1. **共通 `<head>` と固有メタ情報**:
   - `knowledge/brand-tone.md` セクション2.1の `<head>` テンプレートを使用し、`<title>【記事タイトル】 | カップルあれこれ 公式Webマガジン</title>` と固有の `<meta name="description">` を設定する。
   - **厳守**: `<html>` は末尾でのみ閉じる。テンプレートタイトルのまま残さない。
2. **ナビゲーション＆PR表記**:
   - ロゴリンクは `href="index.html"`。
   - ヘッダー／タイトル直下に必ずPR表記を入れる。
     - パターンA/C: `※本記事にはアフィリエイト広告（PR）が含まれています。`
     - パターンB: `※本ページはプロモーションが含まれています`

---

## ステップ2: ブランドトーン準拠の執筆ルール

`knowledge/ng-rules.md` の禁止表現を避けつつ、`@couplearekore` らしい親しみやすく上品なWebマガジン調で執筆する。

### 2.1 文体・情報粒度の基準
- **誇張・AI定型文の排除**: 「いかがでしたでしょうか？」「息を呑む圧倒的美しさ」「絶対に効果あり」等のAI構文・断定誇張を使わない。
- **具体的シーンと実用情報のセット記述**:
  - **パターンA（ギフトまとめ）**: 01〜0N のナンバリング＋短いキャッチバッジ（例：`凛とした、上質なフローラル。`）＋赤字税込価格 `font-bold text-[#bf0000]`（例：`最新価格：約○,○○○円（税込）〜`）＋贈る相手のイメージ・香り／質感の具体描写（3〜4文）。
  - **パターンB（デートスポットランキング）**: `第○位・キャッチ` バッジ＋見どころとカップルでの過ごし方＋`<br><br>` のあとに **`・アクセス：...`** / **`・営業時間：...`** / **`・料金：...`** の一次情報を整理。
  - **パターンC（単体深掘りレビュー）**: 共感リード＋番号付き `h2` セクション＋特徴リスト（`bg-gray-100 rounded p-6`）＋スペック表＋Q&A（注意事項含む）＋まとめ誘導。
- **モバイル最適改行の設計**:
  - `<h1>` や導入文でスマホとPCの折り返しが不自然にならない位置へ `<br class="block md:hidden">` および `<br class="hidden md:block">` を適切に入れる。

## ステップ3: TikTok連動構成の組み込み

`01-research` で公式TikTok動画（`@couplearekore`）が特定された場合、記事構成へ自然に連動させる。
- **リード文でのブリッジ**: 必要に応じて「TikTok（@couplearekore）で反響を呼んだ〜」「動画では伝えきれなかった詳細・アクセスまでまとめました」のように動画視聴者向けの文脈を自然に接続する。
- **記事末尾TikTok動画エリア（まとめ動画がある場合）**:
  - `knowledge/brand-tone.md` セクション4.1の `blockquote.tiktok-embed` カードを挿入する。
  - **厳守**: この段階では `<blockquote class="tiktok-embed" ...>` のみを配置し、`<script src="https://www.tiktok.com/embed.js">` の二重記述は行わない（配置調整は `03-affiliate` が末尾1回に統一する）。

## ステップ4: メディア枠・CTA仮枠＆ `index.html` 用カード文案の準備

- 後続の `03-affiliate` が差し替え・整形しやすいよう、ルート直下へ `article-<slug>.html` の初稿を生成し、以下のプレースホルダー／仕様を合わせる:
  - 場所・店舗・施設を紹介する記事の「各スポット枠」は、建物外観フリー素材をメインに使う前提の記述は書かず、`03-affiliate` の【ハイブリッド画像・スポット表示ルール】（**A. メインビジュアル**：第1優先＝ユーザー指定Instagram埋め込み／第2優先＝楽天トラベル食事・レストラン・内観公式画像／第3優先＝料理・内観イメージ写真、**B. 全スポット共通の標準装備**：店舗情報エリアへのGoogleマップ `<iframe>`＋黒ボタン直上の「📸 Instagramで実際の料理・店内写真を見る」ボタン ※第1優先適用時のみボタン省略可）に対応した構造を用意する。
  - `.reveal` クラスを使う場合（パターンB等）は、ページ末尾の `reveal()` 監視 `<script>` を必ず記述する。
  - 戻るボタン（`<a href="index.html" ...>トップページへ戻る</a>` / `記事一覧に戻る`）とフッターを配置する。
  - `index.html`（`#gift` または `#date`）に追記するタイトル・要約文（50〜90文字）・英語エリア名を用意し、`03-affiliate` へ引き渡す。
