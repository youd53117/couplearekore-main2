# NGルール・禁止表現・過去教訓ナレッジ（ng-rules.md）

このファイルは、記事作成・サイト更新の品質を守るため、**禁止表現・AI構文・過去の修正教訓**を蓄積するナレッジベースです。
執筆担当（`02-writer`）、アフィリエイト・メディア整形担当（`03-affiliate`）、最終検品担当（`04-inspector`）は作業時に必ず本ファイルを参照してください。

> **【自動追記ルール】**
> 検品（`04-inspector`）での差し戻し、またはユーザーからの修正指示・フィードバックが発生した場合は、同じミスを再発させないよう **原因・NG例・正解ルールを本ファイル末尾の「過去教訓ログ」へ必ず自動追記** すること。

---

## 1. 禁止表現・AI構文NG集

読者に「AIが書いた不自然な記事」と感じさせないため、以下の表現・構成を禁止する。

### 1.1 典型的なAI定型文・締めくくり
- **NG**: 「いかがでしたでしょうか？」「この記事では〇〇について詳しく解説しました。ぜひ参考にしてみてくださいね！」のような機械的なまとめ。
- **正解**: 「次の記念日や休日のデート選びに、ぜひ役立ててみてください。」など、メディアの語り口（`knowledge/brand-tone.md`）に沿った自然な余韻・行動提案にする。

### 1.2 過度な美辞麗句・抽象的な褒め言葉の羅列
- **NG**: 「息を呑むほど圧倒的な美しさ」「まるで異世界に迷い込んだかのような極上のひととき」「五感を刺激する至高の空間」など、根拠のない抽象的形容詞の多用。
- **正解**: **具体的な事実とカップル目線のシーン**で魅力を伝える（例：「全面ガラス張りのゴンドラからコスモクロック21を一望」「駅から徒歩6分」「入浴料込みで1日中漫画が読めるおこもりスペース」）。

### 1.3 景表法・誇大表現リスクのある断定語
- **NG**: 「絶対にアレルギーが出ない」「100%効果がある」「日本一安い」「誰が使っても完璧」などの断定的誇張。
- **正解**: 必要に応じて注意書きを添える（例：「アレルギーを起こしにくいとされるサージカルステンレス素材。ただしすべての方に症状が出ないことを保証するものではありません」）。
- ※既存記事の見出し慣用表現（「絶対に外さない」等の編集表現）を除き、効能・機能・価格の事実記述には正確な表現を用いる。

### 1.4 箇条書き乱発・壁文章（改行・レスポンシブ配慮不足）
- **NG**: 1文が長すぎる解説文を改行・余白なしで並べる／「・〇〇：〜」「・△△：〜」だけを機械的に大量出力する。
- **正解**: 2〜4行の自然な紹介文のあとに `<br><br>` で区切り、「アクセス」「営業時間」「料金・最新価格（税込）」等の基本情報を簡潔に整理する。

## 2. HTML・マークアップ過去の修正教訓

本リポジトリの既存記事およびトップページで実際に発生した不具合・再発防止策一覧。

1. **ルート `<html>` タグの即閉じ禁止（`index.html` の過去教訓）**
   - **NG**: `<html lang="ja" style="scroll-padding-top: 120px;"></html>` のように1行目で `</html>` を閉じてしまう。
   - **正解**: `</html>` はファイル最末尾のみに記述する。
2. **閉じタグ重複・ネスト二重化・閉じ忘れ（`article-gift5.html`, `article-girlfriend-gift5.html`, `article-aliba.html` の過去教訓）**
   - **NG**: `</h1></h1>`、`</header></header>`、`<main>` の二重ネスト、余分な `</div>`、未閉じの `<div>`。
   - **正解**: `04-inspector` にて `HTMLParser` によるタグ整合性エラー0件を必須通過条件とする。
3. **テンプレート `<title>` / `<meta description>` の未変更（`article-gift5.html`, `article-kansai.html` の過去教訓）**
   - **NG**: `<title>カップルあれこれ | 公式Webマガジン</title>` のまま公開してしまう。
   - **正解**: 必ず `<title>記事タイトル | カップルあれこれ 公式Webマガジン</title>` と固有の `description` に書き換える。
4. **`.reveal` スクロール監視JSの配置忘れ**
   - **NG**: カードに `reveal` クラスを付けたのに末尾 `<script>` を入れ忘れ、要素が `opacity: 0` のまま画面に表示されない。
   - **正解**: `.reveal` を使う場合は必ずページ末尾に `reveal()` スクロール監視 `<script>` を配置する。
5. **TikTok埋め込みスクリプトの重複記述（`index.html` 注意事項より）**
   - **NG**: 各 `<blockquote>` ごとに `<script async src="https://www.tiktok.com/embed.js"></script>` を貼る。
   - **正解**: 埋め込み先には `<blockquote>...</blockquote>` のみを置き、`<script>` は **ページ最末尾に1回だけ** 配置する。

## 3. メディア・写真選定NG集

1. **ログイン制限のあるSNS埋め込みの原則廃止（`article-yokohama.html` 改定教訓）**
   - **NG**: 閲覧時にログイン画面やプレビュー欠落が起きる Instagram 埋め込みをスポット写真代わりに使う。
   - **正解**: Wikimedia Commons の著作権フリー実物写真をルート直下にローカル保存して `<img>` 表示する。見つからない場合のみ Googleマップ公式埋め込み（`<iframe>`）または楽天アフィリエイト画像枠を使う。
2. **施設の象徴が分からない構図（`yokohama-osanbashi.jpg` 改定教訓）**
   - **NG**:
     - デッキ・床・壁の一部だけを切り取った写真（例：屋上ウッドデッキの木板だけ写った写真）
     - 看板や案内板のみのアップ写真
     - 遠景すぎて対象の建物・施設がどこにあるか判別しづらい写真
   - **正解**: **必ず複数候補をダウンロードして `read_file` で目視比較**し、「その施設の象徴的な外観や建築全体がしっかり映っていて、読者がパッと見た瞬間に『あ、この施設だ』と一目で分かる映える構図」だけを採用する。
3. **ライセンス表記漏れ・商用不可素材の採用**
   - **NG**: `CC BY` / `CC BY-SA` のクレジット未記載、`CC BY-NC`（非商用のみ）や著作権未確認画像の利用。
   - **正解**: Wikimedia Commons のメタデータ（`LicenseShortName`, `Artist`）を確認し、必要な場合は画像直下に `text-[11px] text-gray-400 text-right px-6 pt-2` で著者名・ライセンスを明記する。
4. **画像ファイル名の日本語・スペース混入**
   - **NG**: 日本語名やスペース入り・`#` 等を含む新規ファイル名（URLエンコード崩れの原因）。
   - **正解**: 新規追加画像は半角英数字・ハイフン（`-`）のみ（例: `yokohama-akarenga.jpg`）でルート直下に保存する。

## 4. アフィリエイト・CTAボタンNG集

1. **周辺ホテル一覧・検索結果一覧へのアフィリエイト化（`article-yokohama.html` 改定教訓）**
   - **NG**: 横浜赤レンガ倉庫や大さん橋のように、楽天側に専用チケット・専用施設ページがなく、`https://travel.rakuten.co.jp/yado/spot/...` のような「周辺ホテルの検索結果一覧」になるURLを無理に楽天アフィリエイト化すること。
   - **正解**: 楽天アフィリエイト（`https://hb.afl.rakuten.co.jp/hgc/526779c3.02e0dab7.526779c4.c2c3e62b/?pc=...`）を使うのは、**その施設・商品そのものの専用ページ（楽天トラベル観光体験チケット、ホテル単体予約ページ、楽天市場の商品ページ）が存在する場合のみ**に限定する。該当がない場合は必ず **公式サイトURL** をそのまま設定する。
2. **詳細ボタンの色分け（赤色ボタン使用）禁止**
   - **NG**: 楽天リンクは `bg-[#bf0000]`（赤）、公式リンクは `bg-black`（黒）のようにボタン色を分ける。
   - **正解**: リンク先が楽天・公式のいずれであっても、詳細ボタンはすべてサイト基本カラーの黒（`bg-black hover:bg-gray-800`）に統一する（価格テキスト `text-[#bf0000]` のみ維持）。
3. **詳細ボタン文言の不統一**
   - **NG**: 「スポット詳細をチェックする」「アイテムをチェックする」「公式サイトで見る」「楽天でチェック」等を混在させる（旧記事のみのレガシー仕様）。
   - **正解**:
     - デートスポット・施設記事（パターンB）: `この施設の詳細を見る`
     - 商品・ギフト記事（パターンA / C）: `この商品の詳細を見る`
4. **`target="_blank"` の付け忘れ**
   - **NG**: 外部URL・アフィリエイトURLを同一タブ遷移にする。
   - **正解**: すべての外部リンクに `target="_blank" rel="noopener noreferrer"`（または `target="_blank"`）を付与する。
